Task Reference 任务参考

Every task ships with saved scene reference images (and, for stacking, a nine-grid placement guide) so the initial scene is identical at every site. Arrange objects to match the reference before each episode. 每个任务都附带已保存的场景参考图（堆叠任务另有九宫格摆放引导），保证各站点初始场景一致。每回合开始前，请按参考图摆放物品。

Reference layout files参考布局文件

Each task's references live in the repository under camera_reference/ — e.g. camera_reference/task01_stacking/ contains the nine-grid image plus a machine-readable layout.json describing each cell. Keep these files unchanged and under version control. 每个任务的参考文件保存在仓库的 camera_reference/ 目录——例如 camera_reference/task01_stacking/ 内含九宫格图与描述各格位的机器可读 layout.json。请勿修改这些文件，并纳入版本管理。
