Clone and install克隆与安装

For a new workspace, clone LeRobot first, then fetch the BREE repository into the same workspace and switch to its branch. This places both BREE/ and its matching LeRobot source directly under lerobot/.新建工作区时，先克隆 LeRobot，再在同一工作区获取 BREE 仓库并切换到其分支，使 BREE/ 与配套的 LeRobot 源码直接位于 lerobot/ 根目录。

bash
git clone https://github.com/huggingface/lerobot.git
cd lerobot

Fetch the BREE repository and use its complete code tree:获取 BREE 仓库，并切换到其完整代码版本：

bash
git remote add bree https://github.com/YyyYyy0604/BREE-v1.git
git fetch bree
git switch -c bree-v1 --track bree/main

Create the lerobot environment and install the checked-out code with SO-101 motor support:创建 lerobot 环境，并安装当前代码与 SO-101 舵机依赖：

bash
conda create -y -n lerobot python=3.10
bash
conda activate lerobot
bash
conda install ffmpeg -c conda-forge
bash
pip install -e ".[feetech]" # or "[dynamixel]" for example

The Git steps above set up a new workspace; environment and installation commands follow the repository’s installation documentation. The operating instructions below retain BREE/README.md verbatim.上方 Git 步骤用于新建工作区；环境与安装命令取自仓库安装文档。后续操作说明按 BREE/README.md 原文保留。

Start a later session后续运行入口

In a new terminal, start from the parent directory of lerobot before using the entry commands below. If the terminal is already at the repository root after installation, keep that working directory.后续新开终端时，从 lerobot 仓库的上一级目录使用下方入口命令。安装完成后若已位于仓库根目录，保持当前工作目录即可。

This document assumes that all commands are run from the LeRobot repository root:本文档默认所有命令都从 LeRobot 仓库根目录运行：

bash
cd lerobot
conda activate lerobot

If you are not using a Conda environment, first confirm that the current Python can run python -c "import lerobot".如果使用的不是 Conda 环境，也应先确认当前 Python 能够执行 python -c "import lerobot"。

4. Startup checks and permissions4. 开机检查与权限

4.1 Find serial ports4.1 查找串口

bash
lerobot-find-port

Unplug and reconnect USB devices one at a time to identify the mapping between the four arms and /dev/ttyACM0 through /dev/ttyACM3.逐个拔插 USB，确认四条机械臂与 /dev/ttyACM0～/dev/ttyACM3 的对应关系。

4.2 Grant serial-port permissions4.2 赋予串口权限

bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
sudo chmod 666 /dev/ttyACM2
sudo chmod 666 /dev/ttyACM3

This usually needs to be repeated after powering off a device, reconnecting USB or restarting the system.设备断电、重新插入 USB 或系统重启后，通常需要重新执行。

4.3 Find cameras4.3 查找相机

bash
lerobot-find-cameras opencv

Record the global, left wrist and right wrist camera indices from their actual views. Later commands use 0 / 2 / 4 as an example; if the current detection results differ, update the commands accordingly.根据实际画面记录全局、左腕和右腕相机编号。后面的命令以 0 / 2 / 4 为例；如果本次检测结果不同，必须同步修改命令。
