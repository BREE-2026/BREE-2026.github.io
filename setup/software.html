Software Installation 软件安装

BREE ships as a pinned LeRobot fork with all calibration and evaluation scripts included. Two install paths are supported — Docker (recommended) or a local environment. BREE 以固定版本的 LeRobot 分支发布，内置全部标定与评测脚本。支持两种安装方式——Docker（推荐）或本地环境。

Option A · Docker (recommended)方式 A · Docker（推荐）

The user image ships the full BREE toolchain with pinned dependencies. Build it from the repository root: 用户镜像包含完整 BREE 工具链与固定版本的依赖。在仓库根目录构建：

bash
git clone <repository-url> bree
cd bree
docker build -f docker/Dockerfile.user -t bree:latest .

Run it with the arms and cameras passed through: 运行时将机械臂与相机透传进容器：

bash
docker run -it --privileged \
  --device /dev/ttyACM0 --device /dev/ttyACM1 \
  --device /dev/ttyACM2 --device /dev/ttyACM3 \
  --device /dev/video0  --device /dev/video2  --device /dev/video4 \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  bree:latest bash

Option B · Local environment方式 B · 本地环境

bash
git clone <repository-url> bree
cd bree
conda create -n bree python=3.10 -y
conda activate bree
pip install -e .
Note说明

Hardware extras (e.g. pip install -e ".[so101]") follow the standard LeRobot installation documentation. The exact repository URL will be published on the project page. 硬件附加依赖（如 pip install -e ".[so101]"）请遵循 LeRobot 官方安装文档。仓库确切链接将在项目主页公布。

Grant device permissions赋予设备权限

Serial devices need relaxed permissions. This must be re-run after every power cycle or re-plug: 串口设备需要放开权限。每次断电或重插后都必须重新执行：

bash
sudo chmod 666 /dev/ttyACM0 /dev/ttyACM1 /dev/ttyACM2 /dev/ttyACM3

Find your device indices确认设备编号

Arms机械臂

bash
lerobot-find-port

With the BREE reference machine the mapping is fixed (left follower = ACM0 … right leader = ACM3, plugged in order 0→3). If your machine assigns different ports, adapt the commands in this guide accordingly. 在 BREE 参考主机上映射是固定的（左从臂 = ACM0 …… 右主臂 = ACM3，按 0→3 顺序插入）。如果你的主机分配了不同端口，请相应调整本指南中的命令。

Cameras相机

bash
lerobot-find-cameras opencv

Identify each camera by what it currently sees, and note its index. Reference machine: global = /dev/video0, left wrist = /dev/video2, right wrist = /dev/video4. 根据每台相机当前拍到的画面辨认并记录编号。参考主机：全局 = /dev/video0、左腕 = /dev/video2、右腕 = /dev/video4。
