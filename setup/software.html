Software Installation软件安装

Install the BREE-v1 LeRobot fork, then identify four serial ports and three cameras. A local Linux environment is the direct path for the hardware workflow.安装 BREE-v1 的 LeRobot 分支，再确认四个串口与三台相机。本地 Linux 环境可直接运行硬件操作流程。

Run the commands below from the BREE-v1 repository root.以下命令均在 BREE-v1 仓库根目录运行。

1 · Clone and install1 · 克隆与安装

bash
git clone https://github.com/YyyYyy0604/BREE-v1.git
cd BREE-v1
git checkout e97d1b6e76f29ea91dc4500a3dff76feb2b77bdb
conda create -n bree python=3.10 -y
conda activate bree
conda install ffmpeg=7.1.1 -c conda-forge -y
python -m pip install -e ".[feetech]"
python -c "import lerobot; print(lerobot.__file__)"
lerobot-info

The revision above is the documentation baseline. The SO-101 motor extra is feetech. Install model-specific extras for the policy you use; see pyproject.toml.上面的版本是本指南的对照基线。SO-101 的舵机附加依赖为 feetech。按所用策略安装模型依赖，具体见 pyproject.toml。

2 · Identify devices and grant access2 · 确认设备并赋予权限

bash
lerobot-find-port
sudo chmod 666 /dev/ttyACM0 /dev/ttyACM1 /dev/ttyACM2 /dev/ttyACM3
lerobot-find-cameras opencv

Optional · Docker可选 · Docker

The repository includes a general LeRobot user image. It installs all extras and is not a frozen BREE-specific environment. Build from the checked-out root:仓库提供 通用 LeRobot 用户镜像，会安装全部附加依赖；它并非冻结的 BREE 专用环境。在已检出的仓库根目录构建：

bash
docker build -f docker/Dockerfile.user -t bree:local .
docker run --rm -it \
  --device /dev/ttyACM0 --device /dev/ttyACM1 \
  --device /dev/ttyACM2 --device /dev/ttyACM3 \
  --device /dev/video0 --device /dev/video2 --device /dev/video4 \
  -p 8091:8091 -p 8092:8092 \
  -v "$HOME/.cache/huggingface:/home/user_lerobot/.cache/huggingface" \
  bree:local bash
Note说明

The image runs as user_lerobot. Ensure that user can access the mapped devices and cache. Browser previews in a container require --web-host 0.0.0.0 with the matching published port. Live recording uses GUI windows; configure display access before using it in Docker. NVIDIA GPU access also requires host/container GPU setup.镜像以 user_lerobot 运行，需确保该用户可读写映射的设备与缓存。容器内浏览器预览需设置 --web-host 0.0.0.0 并发布对应端口。实时录制使用 GUI 窗口，在 Docker 中运行前需配置显示访问；NVIDIA GPU 还需配置主机与容器的 GPU 支持。
