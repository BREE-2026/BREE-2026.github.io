BREE Setup Guide — Overview & Prerequisites BREE 搭建指南 — 总览与前置条件

BREE is a bimanual, rigorously-calibrated, low-cost real-world benchmark for evaluating vision-language-action (VLA) policies on tabletop manipulation tasks. This guide takes you from an empty table to calibrated, reproducible evaluations. BREE 是一个双臂、严谨标定、低成本的真机基准平台，用于在桌面操作任务上评测视觉-语言-动作（VLA）策略。本指南带你从一张空桌子开始，完成搭建、标定，直到可复现的评测。

Overview & prerequisites总览与前置条件

  • Estimated time: about 1–2 hours for software installation + system calibration once the hardware is assembled; budget a full afternoon for assembling four SO-101 arms and the camera rig. 预计时间：硬件装配完成后，软件安装 + 系统标定约需 1–2 小时；装配四条 SO-101 机械臂与相机机架建议预留一个下午。
  • Required background: none. The guide is written for non-experts — every command is copy-pasteable. 背景要求：无。本指南面向非专家撰写——所有命令均可直接复制粘贴。
  • Host PC: reference configuration to be synced. For real-time VLA inference (e.g. SmolVLA) a CUDA GPU is expected; 24 GB+ VRAM is recommended for larger VLAs such as pi0-class models. 主机配置：参考配置待同步。实时 VLA 推理（如 SmolVLA）需要 CUDA GPU；如运行 pi0 级别的大型 VLA，建议 24 GB 以上显存。
  • Software: Ubuntu + a pinned LeRobot fork provided in this repository; Docker is the recommended path. 软件：Ubuntu + 本仓库提供的固定版本 LeRobot 分支；推荐使用 Docker。

What is covered内容覆盖

  • Source the hardware, printed fiducials and calibration fixtures (BOM). 采购硬件、打印基准标记与标定夹具（物料清单）。
  • Assemble the workspace: four arms with fixed USB assignment, three cameras, AprilTags (assembly). 装配工作区：四条臂固定 USB 分配、三台相机、AprilTag 标签（装配）。
  • Install the software and identify device indices (software). 安装软件并确认设备编号（软件）。
  • Calibrate all four arms with the midpoint fixture, then all three cameras with reference-save and AprilTag gates (calibration). 用限位夹具标定四条臂，再用参考写入与 AprilTag 门槛校验三台相机（标定）。
  • Run evaluations and compare results on the leaderboard (evaluation). 运行评测并在排行榜对比结果（评估）。

Quick notes快速提示

Tip · Three rules of reproducibility 提示 · 可复现三原则
  • Keep lighting, camera angles and background identical across sessions — this is what the saved references enforce. 保持光照、相机角度与背景在每次会话中完全一致——这正是保存的参考画面所强制的。
  • Never run an evaluation unless every calibration gate reports within_tolerance = true. 任何标定门槛未报告 within_tolerance = true 之前，不要运行评测。
  • When arranging scenes, always follow the task reference images and checklists. 摆放场景时，始终遵循任务参考图与检查清单。
