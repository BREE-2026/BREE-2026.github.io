1. Complete workflow overview1. 完整流程概览

Choose the workflow that matches your current task. Recalibration is not required every time.根据当前工作内容选择对应流程，不需要每次都重新校准。

First installation or hardware replacement首次安装或更换硬件

  1. Identify the serial ports and grant access permissions.确认串口并赋予权限。
  2. Calibrate all four arms.校准四条机械臂。
  3. Confirm that the arms can safely return to the H pose.确认机械臂能够安全回到 H 位。
  4. Confirm the device indices of all three cameras.确认三个相机的设备编号。
  5. Adjust the global camera and both wrist cameras.调整全局相机和两个腕部相机。
  6. Regenerate camera reference files only when the installation baseline needs to be redefined.只有在需要重新定义安装基准时，才重新生成相机参考文件。

Daily workflow after each startup每次开机后的日常流程

  1. Grant access permissions to the serial ports.给串口赋予权限。
  2. Check the serial ports and camera indices.核对串口和相机编号。
  3. Check the arms at the H pose.检查机械臂 H 位。
  4. Use the existing reference images to check the positions of all three cameras.用已有参考图检查三个相机的位置。
  5. Proceed with teleoperation, data collection or model evaluation.进行遥操作、数据采集或模型评估。

Training and evaluation workflow训练与评估流程

  1. Prepare task scene reference images.准备任务场景参考图。
  2. Collect data with lerobot-record.使用 lerobot-record 采集数据。
  3. Train a model with lerobot-train.使用 lerobot-train 训练模型。
  4. Evaluate with lerobot-record, the RDT client or the OpenPI client.使用 lerobot-record、RDT 客户端或 OpenPI 客户端进行评估。
  5. Write all run results to outputs/ under the repository root, rather than to BREE/.所有运行结果统一写入仓库根目录下的 outputs/，不要写入 BREE/。

Result结果Recommended location推荐位置
