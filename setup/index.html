BREE Setup GuideBREE 搭建指南

Build the SO-101 bimanual rig, install the BREE-v1 software, calibrate the arms and cameras, then collect data or evaluate a trained policy.搭建 SO-101 双臂机架，安装 BREE-v1 软件，完成机械臂与相机标定后，采集数据或评测训练好的策略。

Run the commands below from the BREE-v1 repository root.以下命令均在 BREE-v1 仓库根目录运行。

Prerequisites前置条件

  • Four assembled SO-101 arms: two leaders and two followers, plus a global and two wrist cameras.四条装配好的 SO-101 机械臂，包括两条主臂与两条从臂，以及一台全局和两台腕部相机。
  • Linux hardware access, Python 3.10+ and the BREE-v1 LeRobot fork. Use the software page for the versioned installation command.Linux 硬件访问环境、Python 3.10 及以上版本和 BREE-v1 LeRobot 分支；具体版本安装命令见软件页面。
  • A compatible inference device and model-specific dependencies. Confirm checkpoint files, tokenizer assets and task scene images separately.兼容的推理设备与模型依赖；单独核实模型权重、tokenizer 资源及任务场景图。

First installation and daily startup首次安装与日常开机

When时机Steps步骤
First installation / hardware changes首次安装 / 硬件变化Verify devices → calibrate arms → verify H pose → tune and save camera parameters → align all camera references.确认设备 → 标定机械臂 → 验证 H 位 → 调节并保存相机参数 → 对齐三台相机参考。
Daily startup日常开机Grant device access → verify mapping → check H pose → restore camera parameters → compare existing camera overlays → collect or evaluate.赋予设备权限 → 核对映射 → 检查 H 位 → 恢复相机参数 → 对比已有相机叠加 → 采集或评测。
Note说明

The clone includes camera installation references, evaluation templates and ID task scene images. See the ID reference gallery. Model weights and OOD task scenes still need to be prepared separately. Save newly generated check and run artifacts under outputs/.克隆已包含相机安装参考、评测模板与 ID 任务场景图，见ID 参考图库。模型权重与 OOD 任务场景仍需另行准备。新生成的检查与运行产物保存在 outputs/。
