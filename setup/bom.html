Reminder · Use distinct colors提醒 · 使用不同颜色区分操作部分

Print the different manipulable parts of every object using different filament colors. This helps the model learn to associate each language instruction with the intended object or part.所有物体的不同操作部分都应使用不同颜色的耗材打印，帮助模型在学习时准确对应语言指令所指的物体或部位。
