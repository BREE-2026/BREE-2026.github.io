Troubleshooting & Checklists 故障排查与检查清单

Common failure points and the pre-flight checks to run before every session. When in doubt: re-run the calibration checks — they are designed to catch exactly these problems. 常见故障点，以及每次实验前的飞行前检查。拿不准时：重新运行标定检查——它们就是为捕获这些问题而设计的。

Common failure points常见故障点

Symptom现象 Likely cause可能原因 Fix解决办法
Arm not found / Permission denied找不到机械臂 / Permission denied Permissions lost after power cycle or re-plug; arms plugged in wrong order断电或重插后权限丢失；插入顺序不对 Re-run chmod 666 /dev/ttyACM*; re-plug arms in 0→3 order重新执行 chmod 666 /dev/ttyACM*；按 0→3 顺序重插
Cameras on wrong indices相机编号错乱 Cameras re-plugged in a different order相机重插顺序变化 Run lerobot-find-cameras opencv and re-identify each camera by its view运行 lerobot-find-cameras opencv，按画面重新辨认
AprilTag check fails / unreliable detectionAprilTag 检查失败 / 检测不稳定 Wrinkled or curved tag; bad lighting; tag moved标签褶皱或弯曲；光照不佳；标签被移动 Re-print flat at 100% scale, fix lighting, restore tag position, re-run check按 100% 比例重新平整打印，改善光照，恢复标签位置后重检
Ghosting in overlay view叠加画面出现双影 Camera mount bumped / rotated slightly相机支架被碰动或轻微转动 Re-adjust until ghosting disappears, then re-run the AprilTag check重新调整至双影消失，然后重跑 AprilTag 检查
Erratic arm motion during auto-calibration自动校准过程中机械臂动作异常 Arm not firmly clamped机械臂未牢牢固定 Clamp the arm to the table edge and redo the fixture calibration将机械臂固定在桌边后重做夹具标定
Old calibration silently replaced旧标定被静默覆盖 Expected behavior — but recoverable这是预期行为——但可恢复 Previous file is kept as .json.bak next to the new one旧文件会以 .json.bak 形式保留在新文件旁

Consolidated pre-flight checklist统一的飞行前检查清单

  • All four arms on the expected ports (ACM0–ACM3), permissions granted. 四条臂都在预期端口（ACM0–ACM3），权限已放开。
  • All three cameras live on indices 0 / 2 / 4. 三台相机分别在 0 / 2 / 4 编号上出图。
  • Global camera overlay shows no ghosting. 全局相机叠加画面无双影。
  • All three AprilTag checks report within_tolerance = true. 三路 AprilTag 检查全部报告 within_tolerance = true。
  • Lighting and background unchanged since calibration. 标定后光照与背景未发生变化。
  • Scene arranged to match the task reference image exactly. 场景已按任务参考图精确摆放。
  • Correct checkpoint path and task instruction passed to lerobot-record. lerobot-record 传入了正确的检查点路径与任务指令。
Golden rule黄金法则

Policy evaluation only begins after the live scene matches the reference — and the calibration gates say so, not your eyes. 只有当实时场景与参考一致时才开始策略评测——而且要以标定门槛的判定为准，而不是你的眼睛。
