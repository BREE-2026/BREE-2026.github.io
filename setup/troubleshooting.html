Troubleshooting & Checklists故障排查与检查清单

Start with device mapping, the H pose and saved camera overlays. Keep the existing calibration and reference files available while diagnosing drift.从设备映射、H 位与相机参考图叠加开始排查，并保留已有标定与参考文件。

Run the commands below from the BREE-v1 repository root.以下命令均在 BREE-v1 仓库根目录运行。

Common failure points常见故障点

Symptom现象Action处理方式
Serial permission denied or wrong arm串口权限不足或机械臂对应错误Run lerobot-find-port, verify each arm, then grant access to the verified ports after reconnecting.运行 lerobot-find-port 逐臂核对，重连后对实际使用的串口重新赋权。
Left and right wrist views swapped左右腕画面颠倒Identify each view live and edit index_or_path. ACT/SmolVLA templates use 0/4/2; XVLA uses 0/2/4.按实时画面辨认并修改 index_or_path。ACT/SmolVLA 模板为 0/4/2，XVLA 为 0/2/4。
H pose differs between arms机械臂 H 位不一致Check calibration IDs, motor mounting and port mapping. Recalibrate the affected arm with the fixture if needed.核对标定 ID、舵机安装与端口映射，必要时对异常机械臂重新做夹具标定。
Camera overlay has ghosting相机叠加出现双影Restore the arm reference pose, lighting and camera mount; rerun the appropriate image-overlay check.恢复机械臂参考姿态、光照和相机安装位置，再运行对应叠加检查。
Not enough visual features视觉特征不足Improve lighting and visible fixed texture, verify the reference image and inspect alignment output before recording.改善光照与固定纹理可见性，确认参考图，并在录制前检查对齐输出。
Scene image or checkpoint not found找不到场景图或模型权重The template paths are local experiment examples. Prepare the images/weights and update the run JSON. Directory references require picN image names.模板路径是本地实验示例。准备图片与权重后修改运行 JSON；参考图目录需要使用 picN 文件名。
Configuration parser errors配置解析错误Keep dataset.rename_map, scene_reference and evaluation_seed in JSON and pass --config_path.将 dataset.rename_map、scene_reference 与 evaluation_seed 放入 JSON，通过 --config_path 加载。
OpenCV GUI unavailableOpenCV 图形界面不可用The scene recorder uses GUI windows. Check display access and the installed OpenCV build; a headless build does not provide those windows.场景录制器使用 GUI 窗口。检查显示访问和 OpenCV 安装版本，headless 版本不提供此类窗口。
Preview port already in use预览端口被占用Global and right-wrist examples both use 8092. Stop the previous check or select another web port.全局与右腕示例都使用 8092，先停止前一检查或指定其他预览端口。

Before every session每次实验前

  • Confirm all four serial ports and three camera views after reconnecting.重连后确认四个串口与三路相机画面。
  • Verify the H pose and the existing global/left-wrist/right-wrist reference overlays.验证 H 位及已有的全局、左腕、右腕参考图叠加。
  • Keep lighting, mounts, background and task scene references consistent.保持光照、支架、背景及任务场景参考一致。
  • Match the selected checkpoint, task prompt, action units and model camera mapping.匹配所选权重、任务指令、动作单位与模型相机映射。
  • Use a new dataset name for each run and retain configuration and check evidence.每次运行使用新的数据集名，并保留配置与检查证据。
Note说明

Reuse the existing arm calibration and camera references for daily checks. Recalibrate after hardware changes or abnormal H poses; regenerate references only when defining a new installation baseline.日常检查复用已有机械臂标定与相机参考。硬件变化或 H 位异常时重新标定；仅在重新定义安装基准时生成参考图。
