Data Collection数据采集

Check the bimanual teleoperation loop, restore the task scene, then record synchronized arm and camera streams with lerobot-record.确认双臂遥操作链路，恢复任务场景，再通过 lerobot-record 录制同步的机械臂与相机数据。

Run the commands below from the BREE-v1 repository root.以下命令均在 BREE-v1 仓库根目录运行。

1 · Prepare a scene reference1 · 准备场景参考图

Create your task reference directory before recording. In directory mode, use pic1.jpg, pic2.jpg and so on; a single image path can also be used. This directory is a suggested layout, not a bundled task asset.录制前创建本任务的参考图目录。目录模式使用 pic1.jpg、pic2.jpg 等连续命名，也可直接指定单张图片路径。下列结构是建议布局，并非仓库已附带的任务资源。

text
BREE/camera_reference/tasks/YOUR_TASK/
├── pic1.jpg
├── pic2.jpg
└── pic3.jpg

2 · Verify teleoperation2 · 验证遥操作

bash
lerobot-teleoperate \
  --robot.type=bi_so_follower \
  --robot.id=follower_arm \
  --robot.left_arm_config.port=/dev/ttyACM0 \
  --robot.right_arm_config.port=/dev/ttyACM1 \
  --robot.left_arm_config.use_degrees=true \
  --robot.right_arm_config.use_degrees=true \
  --robot.left_arm_config.cameras="{global: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}, wrist: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --robot.right_arm_config.cameras="{wrist: {type: opencv, index_or_path: 4, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --teleop.type=bi_so_leader \
  --teleop.id=leader_arm \
  --teleop.left_arm_config.port=/dev/ttyACM2 \
  --teleop.right_arm_config.port=/dev/ttyACM3 \
  --teleop.left_arm_config.use_degrees=true \
  --teleop.right_arm_config.use_degrees=true \
  --fps=30 \
  --display_data=true

Confirm both leader–follower pairs, joint directions, action units and all camera views. Stop this process before running the recorder.检查两组主从臂对应关系、关节方向、动作单位和所有相机画面。启动录制前先停止遥操作进程。

3 · Record episodes3 · 录制回合

Replace YOUR_NAME/YOUR_DATASET, YOUR TASK DESCRIPTION and YOUR_TASK. Choose episode count and timing for your task. Set camera indices from the live device check.替换 YOUR_NAME/YOUR_DATASET、YOUR TASK DESCRIPTION 与 YOUR_TASK。按任务设置回合数与时间，并根据设备检查结果填写相机编号。

Note说明

For this revision, keep path-valued scene options in a JSON configuration to avoid the command parser issue documented in the evaluation section. The following prepares a recording configuration from the repository’s hardware template, clears its policy, and uses the collection settings in the operating guide.本版本将场景路径选项放入 JSON 配置，以避开评测章节记录的命令解析问题。以下使用仓库中的硬件模板生成录制配置，清除策略，并采用操作指南的数据采集设置。

bash
python - <<'PY'
import json
from pathlib import Path

config = json.loads(Path("BREE/configs/xvla_eval.json").read_text())
config["policy"] = None
config["teleop"] = {
    "type": "bi_so_leader",
    "id": "leader_arm",
    "left_arm_config": {"port": "/dev/ttyACM2", "use_degrees": True},
    "right_arm_config": {"port": "/dev/ttyACM3", "use_degrees": True},
}
config["dataset"].update({
    "repo_id": "YOUR_NAME/YOUR_DATASET",
    "single_task": "YOUR TASK DESCRIPTION",
    "num_episodes": 50,
    "episode_time_s": 60,
    "reset_time_s": 40,
    "push_to_hub": False,
    "rename_map": {},
})
config.update({
    "scene_reference": "BREE/camera_reference/tasks/YOUR_TASK",
    "scene_reference_camera": "global",
    "scene_overlay_alpha": 0.4,
    "episodes_per_reference": 1,
    "scene_reference_cycle": False,
    "evaluation_seed": None,
    "scene_home_requires_h": True,
    "require_leader_home_alignment": True,
    "leader_home_tolerance": 8,
})
Path("outputs/record").mkdir(parents=True, exist_ok=True)
Path("outputs/record/collect.json").write_text(json.dumps(config, indent=2) + "\n")
PY

Edit outputs/record/collect.json before running. It starts from global / left wrist / right wrist 0 / 2 / 4; update all ports, camera indices, dataset name, task prompt and scene path. In directory mode, provide enough numbered images for the selected episode count or deliberately enable scene_reference_cycle.运行前编辑 outputs/record/collect.json，初始相机映射为全局 / 左腕 / 右腕 0 / 2 / 4。核对串口、相机编号、数据集名、任务指令与场景路径。目录模式需要准备足够的连续编号图片，或按实验设计启用 scene_reference_cycle。

bash
HF_HUB_DISABLE_XET=1 lerobot-record \
  --config_path=outputs/record/collect.json

The recorder shows a scene overlay before each episode. With this configuration, press H to return home before arranging the scene; Enter starts recording once home alignment is satisfied. Recordings remain local because dataset.push_to_hub=false.录制器会在每回合前显示场景叠加。此配置下，先按 H 回 H 位再整理场景，满足主从臂姿态对齐后按 Enter 开始。dataset.push_to_hub=false 表示录制数据仅保存在本地。

4 · Check the recorded data4 · 复核录制数据

  • Check the recorded episode count, task text and synchronized videos before training.训练前核对已录回合数、任务文本与同步视频。
  • The raw camera keys are observation.images.left_global, observation.images.left_wrist and observation.images.right_wrist.原始相机键为 observation.images.left_global、observation.images.left_wrist 与 observation.images.right_wrist。
  • Keep degree-based states/actions consistent with training and inference. Retain the configuration, source revision and reference images.保持状态与动作的角度单位在采集、训练和推理间一致，并保存配置、源码版本和参考图。

For ACT, SmolVLA, XVLA, RDT and OpenPI training, use the model-specific recipes in the training guide.ACT、SmolVLA、XVLA、RDT 与 OpenPI 训练流程见 模型训练指南。
