Abstract

Reproducibility, by construction 可复现性，从构建方式上保证

Real-world evaluation of vision-language-action (VLA) policies is hard to reproduce: camera mounts drift, arm calibration varies silently between labs, and most low-cost platforms are single-arm. BREE is a bimanual real-world benchmark built entirely from off-the-shelf components — four SO-101 arms (two leaders, two followers), one global and two wrist cameras — that any lab can rebuild and obtain consistent results with. Where typical setups stop at eyeballing visual alignment, BREE enforces reproducibility with quantitative gates: fixture-based midpoint calibration for every arm, an AprilTag reference save / re-check workflow for every camera, and automated pass/fail verdicts that must pass before any evaluation run. Data collection, SmolVLA / ACT training, and standardized evaluation all run on the LeRobot stack. 视觉-语言-动作（VLA）策略的真机评测很难复现：相机会漂移、机械臂标定在实验室之间悄悄不一致，且多数低成本平台只有单臂。 BREE 是一个全部使用现成组件搭建的双臂真机基准平台——四条 SO-101 机械臂（双主臂 + 双从臂）、一台全局相机与两台腕部相机——任何实验室都能重建并获得一致的结果。 与仅凭肉眼对齐的常见做法不同，BREE 用量化门槛来保证可复现性：每条臂都经过限位夹具中点标定；每台相机都执行 AprilTag「参考写入 / 复检」工作流； 任何评测运行之前都必须通过自动化的 pass/fail 判定。数据采集、SmolVLA / ACT 训练与标准化评测全部基于 LeRobot 生态。

Platform

A dual-arm platform anyone can rebuild 任何人都能重建的双臂平台

Every component is off-the-shelf and open. Fixed USB port assignment (ACM0–ACM3) and fixed camera indices make the four arms and three cameras plug-and-play identical across rebuilds. 所有组件均为现成商品与开源硬件。固定的 USB 端口分配（ACM0–ACM3）与固定相机编号，使四条臂与三台相机在每次重建中即插即用、完全一致。

Why BREE is rigorous

Calibration with quantitative gates 带量化门槛的标定体系

Three layers of calibration — mechanical, visual and fiducial — each with a measurable acceptance criterion and an automated verdict. No step relies on "it looks about right". 三层标定——机械、视觉、基准标记——每一层都有可度量的验收标准和自动判定，不依赖任何"看起来差不多"的环节。

Fixture-based midpoint arm calibration限位夹具中点标定（机械臂）

Each of the four arms is seated in a physical midpoint fixture; a one-command script calibrates all motors, writes the result to the motors, and automatically backs up any previous calibration file (.json.bak). 四条臂逐一放入物理限位夹具，一键脚本完成全部电机标定、写回电机，并自动备份原有标定文件（.json.bak）。

Global camera alignment by image overlay全局相机参考图叠加对齐

A saved reference frame is blended 50/50 with the live feed in a browser view; the camera is adjusted until fixed structures (mount beam, base outlines, table edge) show no ghosting. 将已保存的参考画面与实时画面在网页中以 50/50 叠加显示，调整相机直到固定结构（横梁、底座轮廓、桌沿）不再出现双影。

AprilTag reference save & re-checkAprilTag 参考写入与复检

Every camera saves an AprilTag pose reference (tag 0 · 80 mm for the global camera; tags 1/2 · 50 mm for the wrists). Re-check recomputes the live detection and compares it against the reference, producing a quantitative report and a within_tolerance verdict. 每台相机保存一个 AprilTag 位姿参考（全局相机用 0 号 · 80 mm；左右腕部用 1/2 号 · 50 mm）。复检时重新检测当前位姿并与参考比对，输出量化报告与 within_tolerance 自动判定。

Acceptance thresholds验收阈值

A re-mounted camera passes only if all metrics are within tolerance — verified automatically, not by eye: 重新安装的相机必须所有指标都在容差内才算通过——由程序自动判定，而非肉眼：

Camera相机 Tag标签 Center error中心误差 Scale change尺度变化 Rotation error旋转误差

The check also reports corner RMS error (px) and writes alignment.jpg — red box = saved reference, green box = current detection — plus a machine-readable JSON. 检查还会输出角点 RMS 误差（px），并生成 alignment.jpg（红框=保存的参考，绿框=当前检测）与机器可读的 JSON 报告。

Data → Training → Evaluation

An end-to-end LeRobot pipeline 端到端 LeRobot 流水线

1 · Bimanual teleoperation & recording1 · 双臂遥操作与录制

Demonstrations are captured with bi_so_leader → bi_so_follower teleoperation, recording 12-DoF bimanual states/actions and three synchronized camera streams into a LeRobotDataset. 通过 bi_so_leader → bi_so_follower 遥操作采集示教数据，录制 12 自由度双臂状态/动作与三路同步相机流，直接写入 LeRobotDataset。

2 · Policy training (SmolVLA / ACT)2 · 策略训练（SmolVLA / ACT）

One-command training from the SmolVLA base checkpoint (or ACT from scratch) with a fixed 3-camera / 12-DoF input specification, so every group trains on identical inputs. 从 SmolVLA 基座检查点（或从零训练 ACT）一键启动训练，固定"3 相机 / 12 自由度"输入规格，确保各组输入完全一致。

bash
HF_HUB_DISABLE_XET=1 lerobot-train \
  --policy.path=lerobot/smolvla_base \
  --policy.vlm_model_name=HuggingFaceTB/SmolVLM2-500M-Video-Instruct \
  --policy.input_features='{...12-DoF state + 3 cameras...}' \
  --policy.chunk_size=50 --policy.n_action_steps=10 \
  --dataset.repo_id=<your-org>/<task-dataset> \
  --steps=50000 --batch_size=8 --policy.device=cuda

3 · Standardized real-world evaluation3 · 标准化真机评测

Evaluation replays the calibrated rig via lerobot-record with the trained policy attached — fixed episodes, reset windows and scene references — and logs per-episode outcomes. 评测通过 lerobot-record 挂载训练好的策略在已标定机架上执行——固定的回合数、重置时间与场景参考——并逐回合记录结果。

bash
lerobot-record \
  --robot.type=bi_so_follower --robot.id=follower_arm \
  --robot.left_arm_config.port=/dev/ttyACM0 \
  --robot.right_arm_config.port=/dev/ttyACM1 \
  --teleop.type=bi_so_leader \
  --policy.path=outputs/train/<run>/checkpoints/<step>/pretrained_model \
  --dataset.single_task="stack two blocks" \
  --dataset.num_episodes=10 --dataset.episode_time_s=40
