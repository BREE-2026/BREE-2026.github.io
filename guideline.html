Guideline / documentation

Build a node.

Assemble the hardware and install the software, then calibrate the arms and align the camera references. Use the task guides to prepare scenes before collecting episodes or evaluating a trained policy.

Build the cell

Build the 4040 frame with the dimensioned drawing and frame BOM, then mount the arms, cameras and lighting.

Open assembly guide ↗

Install the stack

Install the LeRobot fork and Feetech dependencies, identify serial ports and cameras, and configure device access.

Open software guide ↗

Calibrate the system

Calibrate the arms, verify the H pose, standardize camera parameters, and align three live views with saved references.

Open calibration guide ↗

Collect an episode

Check teleoperation, prepare task scene images, and record synchronized arm and camera streams with a saved configuration.

Open collection guide ↗

Run evaluations

Browse real ID layouts and distribution guides, prepare OOD scenes, then evaluate with matched configurations.

Open evaluation guide ↗

Prepare task scenes

Check the eight task identifiers, match prompts to the selected model, and define scene references and success criteria.

Open task guide ↗

Diagnose drift

Check port mapping, H poses, camera overlays and configuration fields when recording or evaluation fails.

Open troubleshooting ↗
