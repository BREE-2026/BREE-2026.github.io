From one protocol to many tasks

Real motion is
the dataset.

Every task is captured under the same physical specification, camera geometry and acceptance gates. The resulting episodes can be pooled across sites without erasing where they came from.

Current repository stills are used in this motion prototype. Production task videos drop into the same frames.

The benchmark claim

Reproducibility is an experimental result, not a setup claim.

Small changes in camera pose, illumination, robot calibration and task objects alter the observation and action distributions. BREE therefore treats the physical environment as part of the benchmark specification.

Each independently assembled node passes the same measurable gates before it can contribute demonstrations or report an evaluation result.
